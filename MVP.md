# MVP Plan - Game Organization Bot

## Дата создания: 5 февраля 2026

## ✅ Выполнено

### Инфраструктура
- [x] Структура проекта (TypeScript + Node.js)
- [x] Docker + Docker Compose конфигурация
- [x] GitHub Actions CI/CD
- [x] База данных PostgreSQL + TypeORM

### База данных
- [x] Модели: User, Group, GroupMember, Game, GameParticipant
- [x] Отношения между сущностями
- [x] Enum для статусов (GameStatus, ParticipationStatus, GroupRole)

### Сервисы
- [x] UserService - регистрация и управление пользователями
- [x] GroupService - создание и управление группами
- [x] GameService - создание игр, запись участников, приоритеты

### Базовые команды бота
- [x] /start - приветствие
- [x] /help - помощь
- [x] /mygroups - список групп пользователя
- [x] /creategroup - начало создания группы (заглушка)
- [x] Inline кнопки для навигации по группам

## 🚧 В работе

### Создание и управление группами
- [ ] **Диалог создания группы**
  - Ввод названия
  - Опционально: описание
  - Выбор: приватная/открытая
  - Генерация invite code для приватных
  
- [ ] **Приглашение участников**
  - Кнопка "Пригласить" в меню группы
  - Генерация ссылки-приглашения
  - Команда /join <invite_code>
  
- [ ] **Управление участниками (для админов)**
  - Назначить админом
  - Удалить из группы
  - Список участников с ролями

### Создание игр
- [ ] **Диалог создания игры** (через кнопку в группе)
  - Шаг 1: Выбор вида спорта (кнопки: Футбол ⚽, Волейбол 🏐, Баскетбол 🏀, Другое)
  - Шаг 2: Дата и время (текстом или календарь)
  - Шаг 3: Место проведения
  - Шаг 4: Мин/макс участников
  - Шаг 5: Стоимость (опционально)
  - Шаг 6: Дополнительные заметки (опционально)
  - Подтверждение и создание

- [ ] **Отображение игры**
  - Карточка с информацией
  - Список участников с приоритетами (✅ Точно, ❓ Не точно, 👤 Гость)
  - Счетчик мест: "8/10 участников"
  - Кнопки действий

### Запись на игры
- [ ] **Кнопки для участников**
  - ✅ Точно иду
  - ❓ Не точно
  - ❌ Отписаться
  - 
- [ ] **Логика приоритетов**
  - Автоматическая сортировка по статусу
  - Обновление позиций при изменениях
  - Список ожидания если мест нет

- [ ] **Для админов группы**
  - Кнопка "➕ Добавить гостя"
  - Диалог ввода имени гостя
  - Гость попадает в конец очереди

### Просмотр игр
- [ ] **Список игр группы**
  - Предстоящие игры (по дате)
  - Карточка каждой игры с кратким описанием
  - Кнопка "Подробнее"

- [ ] **Детальная карточка игры**
  - Вся информация об игре
  - Три списка участников:
    - ✅ Точно идут (X человек)
    - ❓ Не точно (Y человек)
    - 👤 Гости (Z человек)
  - Список ожидания (если игра заполнена)
  - Кнопки записи/отписки

### Уведомления
- [ ] **При создании игры**
  - Отправка сообщения всем участникам группы
  - С тегами @username (если есть)

- [ ] **При записи/отписке**
  - Уведомление создателя игры
  - Если набрался минимум - уведомление всем

- [ ] **Напоминание**
  - За 24 часа до игры - всем записавшимся

## Технические детали

### Управление состоянием диалогов
Для многошаговых диалогов нужен механизм хранения состояния:
- Вариант 1: Использовать telegraf-session (в памяти или Redis)
- Вариант 2: Хранить временное состояние в БД (таблица user_states)
- Вариант 3: Использовать Scenes от Telegraf

### Форматирование сообщений
- Использовать Markdown для красивого отображения
- Emoji для визуального разделения
- Inline кнопки для всех действий

### Оптимизация
- Кеширование списков групп
- Пагинация для больших списков
- Debounce для частых обновлений
